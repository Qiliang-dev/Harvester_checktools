YAML Editor 安装说明
====================

快速安装指南
-----------

方法一：直接使用（推荐）
1. 下载 YAML_Editor.exe 文件
2. 双击运行，无需安装任何其他软件
3. 开始使用！

方法二：从源代码运行
1. 确保已安装 Python 3.7 或更高版本
2. 安装依赖包：
   pip install tkinterdnd2 ruamel.yaml pyyaml
3. 运行程序：
   python YamlChange_noQT.py

系统要求
--------
- Windows 10 或更高版本
- 至少 100MB 可用磁盘空间
- 建议 4GB 或更多内存

注意事项
--------
- 首次运行可能需要几秒钟启动时间
- 如果遇到安全软件警告，请选择"允许运行"
- 建议在编辑重要文件前先备份

技术支持
--------
如有问题，请查看 README.md 文件中的详细说明。
