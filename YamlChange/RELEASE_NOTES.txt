YAML Editor v1.0 发布说明
========================

发布日期: 2024年1月

新功能
------
✓ 支持主分类简单值编辑（Name、Description、time、TestNotes等）
✓ 支持复杂嵌套结构的YAML文件编辑
✓ 支持Vehicle类型的Seat/Door过滤
✓ 支持Item子属性的编辑
✓ 拖拽文件功能
✓ 批量文件编辑
✓ 实时状态反馈

技术改进
--------
✓ 优化了文件加载逻辑
✓ 改进了界面响应速度
✓ 增强了错误处理机制
✓ 修复了主分类编辑功能

已知问题
--------
- 不支持数组类型的属性编辑
- 不支持添加新属性或删除现有属性
- 仅支持包含TestCase根节点的YAML文件

系统兼容性
----------
✓ Windows 10
✓ Windows 11
✓ 支持高分辨率显示器

安装包内容
----------
- YAML_Editor.exe (主程序)
- README.md (详细使用说明)
- INSTALL.txt (快速安装指南)
- RELEASE_NOTES.txt (本文件)

使用建议
--------
1. 首次使用建议先在小文件上测试
2. 编辑重要文件前请先备份
3. 如遇到问题请查看README.md中的故障排除部分

后续计划
--------
- 支持更多YAML结构类型
- 添加撤销/重做功能
- 支持配置文件导入导出
- 优化大文件处理性能
