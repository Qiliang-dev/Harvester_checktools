# Harvester Checktools - 测试文件管理工具集

## 项目概述

Harvester Checktools 是一个专门用于汽车测试数据管理和验证的工具集，主要解决测试工程师在处理大量YAML配置文件、Excel数据表格和测试文件时的效率问题。该工具集包含多个专门化的工具，用于自动化测试文件的分类、验证、转换和管理。

### 目标用户
- 汽车测试工程师
- 数据分析师
- 测试数据管理员
- 质量保证团队

### 核心价值
- 自动化测试文件分类和验证
- 提高测试数据管理效率
- 减少人工错误
- 标准化测试流程

## 核心功能

### 1. YAML分类器 (yaml_classifier.py)
**功能描述**: 自动分析YAML测试配置文件，根据座位位置、呼吸模式、频率等参数进行分类
**核心特性**:
- 批量处理YAML文件
- 智能分类算法（座位位置、手柄状态、呼吸模式、频率）
- Excel结果导出
- 实时搜索和过滤
- 可视化分类结果

**技术实现**:
- 使用PyYAML解析YAML文件
- openpyxl处理Excel文件
- tkinter构建GUI界面
- 正则表达式进行模式匹配

### 2. 文件名检查工具 (NameCheck)
**功能描述**: 比较Excel文件和文件夹中的文件名，验证测试文件的完整性
**核心特性**:
- Excel文件解析和提取
- 文件夹文件完整性检查
- 重复文件名检测
- 测试编号统计
- 结果格式化和导出

**技术实现**:
- pandas处理Excel数据
- 文件系统遍历
- 模式匹配算法
- 模块化UI设计

### 3. YAML转换工具 (YamlChange)
**功能描述**: 批量修改和转换YAML测试配置文件
**核心特性**:
- YAML文件批量编辑
- 模板化配置
- 版本控制支持
- 配置验证

**技术实现**:
- YAML解析和生成
- 模板引擎
- 配置验证逻辑

### 4. 文件排序工具 (Sort)
**功能描述**: 对测试文件进行智能排序和整理
**核心特性**:
- 多维度排序算法
- 批量重命名
- 文件组织优化

## 用户体验

### 用户流程
1. **数据准备**: 用户准备YAML文件、Excel表格和测试文件
2. **工具选择**: 根据需求选择合适的工具（分类、检查、转换、排序）
3. **参数配置**: 设置工具参数和输出选项
4. **批量处理**: 执行自动化处理
5. **结果验证**: 查看处理结果和报告
6. **数据导出**: 导出处理后的数据

### 界面设计原则
- 简洁直观的操作界面
- 实时进度反馈
- 错误提示和帮助信息
- 结果可视化展示

## 技术架构

### 系统组件
1. **核心处理引擎**: 负责文件解析、数据分析和结果生成
2. **GUI界面层**: 提供用户交互界面
3. **数据存储层**: 处理Excel、YAML等格式的数据
4. **配置管理**: 管理工具参数和设置

### 数据模型
- **测试用例模型**: 包含座位、呼吸模式、频率等属性
- **文件信息模型**: 文件名、路径、大小、修改时间等
- **分类结果模型**: 分类标签、文件列表、统计信息

### 技术栈
- **编程语言**: Python 3.6+
- **GUI框架**: tkinter
- **数据处理**: pandas, openpyxl, PyYAML
- **文件操作**: os, pathlib
- **打包工具**: PyInstaller

## 风险和缓解措施

### 技术风险
1. **文件格式兼容性**
   - 风险: 不同版本的YAML/Excel格式可能导致解析错误
   - 缓解: 实现格式检测和兼容性处理，添加错误恢复机制

2. **大数据量处理性能**
   - 风险: 处理大量文件时性能下降
   - 缓解: 实现分批处理和进度反馈，优化算法效率

3. **内存使用**
   - 风险: 大文件可能导致内存溢出
   - 缓解: 使用流式处理和内存管理

### 功能风险
1. **分类准确性**
   - 风险: 自动分类可能产生错误
   - 缓解: 添加人工验证机制，提供分类规则配置

2. **数据完整性**
   - 风险: 处理过程中可能丢失数据
   - 缓解: 实现数据备份和恢复机制

### 用户接受度风险
1. **学习成本**
   - 风险: 用户可能需要时间适应新工具
   - 缓解: 提供详细文档和培训材料，设计直观的界面

2. **工作流程改变**
   - 风险: 现有工作流程需要调整
   - 缓解: 提供渐进式迁移方案，保持向后兼容
